# Study Vault

The application source is in [`study-vault/`](study-vault/). The existing [`study-vault-.Ver1.zip`](study-vault-.Ver1.zip) package mirrors that source tree. Study Vault is the ISU-Ilagan thesis and research repository for Information Technology students and alumni.

## Run the application

Study Vault is a PHP 8+ / MySQL application. Follow the complete XAMPP, database, and mail-verification setup in [`study-vault/README.md`](study-vault/README.md), then open the project through Apache at `/study-vault/`.

## Interface direction

The web experience has been redesigned around an academic repository rather than a generic records-management template: an ISU forest-green and seal-gold identity, editorial paper-inspired research pages, a responsive discovery and account experience, a dedicated administrator workspace, and a focused protected manuscript reader. Existing PHP workflows, database operations, role checks, verification, subscriptions, and manuscript security remain the source of truth.
